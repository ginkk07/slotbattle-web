# 拉霸戰鬥 HUD 美術素材 V2

## 血條位置更新

玩家與怪物血條統一放在各自角色腳底，水平置中於角色腳底錨點。兩者共用相同血條圖片與 154 邏輯像素顯示寬度；血條本體頂端距腳底 5 邏輯像素。組合預覽與互動預覽均採此規則，血條不再放在怪物名稱下方。

## V2.1 劍圖示修正

劍身、護手、握柄與尾柄改為單一連續輪廓；收窄劍身，縮小尾柄，移除原本握柄接縫與雙護手般的外形。六張劍圖示共用完全相同的 alpha 輪廓、256 × 256 畫布與中心錨點：卡片攻擊、技能攻擊／停用、HUD 攻擊、出牌／停用。組合預覽及獨立預覽頁同步更新。

修正對照：`previews/sword-comparison.png`。

這套素材依已確認的直式 9:16 概念圖重製，設計座標為 450 × 800。背景、卡底、技能底座與按鈕的美術由內建 image_gen 製作；輸出後統一 PNG 畫布與錨點。圖示延伸既有 BattleIcon 圖形系統，輸出為獨立 PNG；角色沿用既有騎士與石像怪，整理透明邊距和腳底位置。

## 使用方式

- `background/`：一張完整 1080 × 1920 遺跡背景，已畫入下方暗部。背景包含場景，未含角色、文字、數值或 UI。
- `cards/`：一般卡底、發光卡底及單獨光暈層。卡面不含符號；符號位於 `icons/cards/`。
- `controls/`：技能底座、主按鈕與次按鈕的各種狀態；素材內沒有文字與圖示。
- `icons/skills/`：技能圖示的一般與停用版本。
- `icons/hud/`：戰鬥傷害、護甲、AP、金幣、物品、設定、出牌及結束回合圖示。
- `characters/`：768 × 768 的透明角色 PNG，腳底錨點固定為 (384, 704)。
- `health/`：血條底座與兩種填色，使用同一張畫布。
- `sources/native/`：可編輯 SVG 圖示與血條來源；`sources/native-index.json` 記錄來源對應。完整生成原圖與提示詞保留在已交付素材包。
- `manifest.json`：完整素材清單、尺寸、錨點與技能圖示對應。
- `validation.json`：尺寸、透明度與狀態對位檢查結果。
- `previews/hud-assembly.png`：以本包素材組成的 9:16 畫面，文字和數字為示意。
- `previews/asset-overview.png`：整套美術與狀態一覽。
- `preview.html`：獨立預覽頁；點卡片、技能或按住按鈕可檢查各種狀態，也能切換停用狀態。與素材目錄一起開啟即可；圖片直接讀取相對路徑 PNG 檔案。

## 避免狀態切換偏移

同一類素材的所有狀態必須使用相同的顯示框。切換時只換 PNG，選取卡片則移動整張卡片及其符號。不要逐張 trim、用不同 object-fit、單獨縮放選取圖或變更透明邊距。

卡片的一般與發光 PNG 保留同一份卡面像素，光暈僅加入卡身外側。技能與按鈕的停用／按下狀態保留同一份 alpha 輪廓。光暈、邊線與表面陰影均已在圖片內；遊戲程式只需處理文字、位置、縮放和動作。

在 450 × 800 座標中，若卡身設定為 108 × 192，PNG 顯示框為 128 × 224，左上位置相對卡身偏移 (-10, -16)。一般／發光都沿用此位置。技能本體為 50 × 50 時，PNG 顯示框為 64 × 64，偏移 (-7, -7)。全遊戲再用同一比例縮放。

血條填色透過左側裁切顯示目前生命百分比，保留圖片本身比例；底座與數值保持固定位置。

角色使用既有美術，未重畫角色造型。本包已接入遊戲的開場與戰鬥畫面。

## GitHub 素材整理

此目錄包含 43 張主要 PNG、原生 SVG 與三張組合／比較預覽，保留素材包的尺寸及 SHA-256。互動預覽讀取獨立 PNG；腳底血條配置見 `layout.json`。遊戲已使用這批背景、角色、卡片、技能、按鈕與血條，並沿用既有戰鬥指令與動畫。
