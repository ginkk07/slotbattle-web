# UI V3：灰白與深灰的幾何遊戲介面

2026-10-13（Asia/Taipei），依使用者指定的《崩壞：星穹鐵道》UI 方向製作。以實際遊戲介面的灰白主按鈕、深色次按鈕、單色圖示、細金色選取線、切角面板與無襯線文字為參考。遊戲仍採 450 × 800、9:16 固定布局；無人物標題主美術沿用獨立遺跡場景。

## 資產與製作方式

本組為原創幾何 UI 素材：可編輯 SVG 母版 → Sharp 輸出 PNG。沒有複製其他遊戲的圖片、商標或文字。按鈕外框、內框、端部細線、陰影與各狀態均在 PNG 中；介面負責文字、圖示、固定布局和狀態切換。PNG 為獨立二進位檔案，沒有 Base64 內嵌。

- 8 張行動按鈕：主／次按鈕各有一般、懸停、按下、停用狀態，1024 × 352。
- 3 張技能底座：一般、選取、停用，256 × 256。
- 2 張卡框：一般、選取，512 × 896。
- 2 張配置選項底圖，256 × 256。
- 2 張單色圖示圓底，128 × 128。
- 1 張淺色視窗底圖，1024 × 1024。
- 每張素材都有同名 `sources/*.svg` 母版；完整尺寸、SHA-256 與 alpha 雜湊見 `manifest.json`。
- 生成器為 `scripts/create-ui-art.mjs`，需可用的 Sharp 套件；可透過 `SLOTBATTLE_ASSET_RUNTIME` 指定既有 Node 套件目錄。遊戲執行與發布不依賴該生成器或 Sharp。

## 固定座標與互動

行動按鈕各狀態的 alpha 雜湊完全相同，切換素材不移動像素輪廓。按鈕與技能點選框維持原位。

卡框本體 x=40、y=64、432 × 768 位於 512 × 896 畫布；對應邏輯卡身為 90 × 160。選取時卡框與三個符號一起上浮 6 邏輯像素（180ms），點選框、手牌列與操作按鈕保持原位。選取框與標記位於既有透明邊距內，不裁切圖示。
